这个目录是「额外分类」的入口 —— 不用改任何代码，丢一个 json 进来就多一个分类。

用法
----
1) 在这里新建一个 json，文件名随你，比如  mycat.json
2) 内容是「分类名 : 词条数组」，键名就是分类名：

   {
     "我的分类": ["词条一", "词条二", "词条三"]
   }

3) 重启 ComfyUI。抽取器下拉里会多出「我的分类」，
   皮肤也会自动给它从 EXTRA_PALETTE 里分配一个灯色。

规则
----
· 键名 = 分类名（会直接显示在节点上，起个看得懂的名字）
· 值必须是字符串数组
· 词条里带换行会被自动拆成多条（和内置分类一样的清洗逻辑）
· 只会读本目录下的 *.json，其它后缀一律忽略

排序说明
--------
内置那 7 个分类（古装 / 古风 / 艺术摄影 / cos / 糖水少女 / NSFW / 抽卡）
的顺序是钉死的 —— 老工作流存的是「第几个分类」，顺序一变就对不上。
你加的额外分类一律排在它们后面，所以怎么加都安全。
